# 抖音参考视频下载

这是一个最小权限的 Chrome 扩展。打开弹窗时，它优先读取当前抖音作品页提供的 MP4 版本信息，将同一作品的不同清晰度和编码合并到一张卡片，在选择框中切换版本；页面没有版本信息时，再读取播放器地址。它不读取、导出或保存 Cookie，也不会把视频发到第三方下载网站。

## 安装与使用

1. 打开 Chrome 的 `chrome://extensions`，开启「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择扩展目录 `tools/BudongChromeExt/douyin-reference-downloader`。
3. 打开目标抖音作品页并播放视频，点击扩展图标。插件会自动列出当前页面可检测的视频；页面刚加载时可点右上角的「重新检测」。
4. 在视频卡片中选择清晰度和编码，再点「下载」。在 Chrome 弹出的保存窗口选择目录，保存后用播放器确认画面和声音。

如果之前从旧目录 `tools/douyin-reference-downloader` 加载过扩展，需要在 `chrome://extensions` 移除旧扩展，再按上面的新路径重新加载；之后修改扩展时可点击刷新图标。当前版本 0.4.2。插件只检测当前选中的抖音标签页；若打开的是其他网站，会在弹窗中显示当前网站。用户主页或搜索页弹窗切换作品时，插件会尝试读取当前作品的详情，包括当前页面已加载的搜索结果。页面提供的文件大小是预计值，实际大小以下载完成为准。一个作品只显示一张卡片，不同清晰度和编码在选择框中切换。读到当前作品的博主昵称时，保存文件名会以昵称开头，例如 `博主昵称-作品标题-作品ID-清晰度.mp4`；读不到昵称时沿用原文件名。

支持 `douyin.com/video/<作品 ID>` 和用户页 `?modal_id=<作品 ID>`。如果页面没有提供直接的 HTTPS 视频源，扩展会提示失败，不会尝试提取浏览器会话材料或绕过站点限制。请仅下载你有权用于本地参考的内容；不要把参考片画面或声音直接用于新作品发布。
