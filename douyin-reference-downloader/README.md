# 抖音参考视频下载

这是一个最小权限的 Chrome 扩展。打开弹窗时，它优先读取当前抖音作品页提供的 MP4 版本信息，将同一作品的不同清晰度和编码合并到一张卡片，在选择框中切换版本；页面没有版本信息时，再读取播放器地址。它不读取、导出或保存 Cookie，也不会把视频发到第三方下载网站。

## 安装与使用

1. 打开 Chrome 的 `chrome://extensions`，开启「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本项目的 `douyin-reference-downloader` 目录（包含 `manifest.json`）。
3. 打开目标抖音作品页并播放视频，点击扩展图标。插件会自动列出当前页面可检测的视频；页面刚加载时可点右上角的「重新检测」。
4. 在视频卡片中选择清晰度和编码，再点「下载」。请保持抖音标签页打开，视频取回后由 Chrome 保存到下载目录。需要每次选择目录时，请在 Chrome 设置中开启「下载前询问每个文件的保存位置」。

如果之前从旧目录 `tools/douyin-reference-downloader` 加载过扩展，需要在 `chrome://extensions` 移除旧扩展，再按上面的新路径重新加载；之后修改扩展时可点击刷新图标。当前版本 0.4.3。插件只检测当前选中的抖音标签页；若打开的是其他网站，会在弹窗中显示当前网站。用户主页或搜索页弹窗切换作品时，插件会优先读取当前播放器的作品详情，兼容不含旧 `data-e2e-vid` 标记的新版页面；初始页面数据仅作兜底。页面提供的文件大小是预计值，实际大小以下载完成为准。一个作品只显示一张卡片，不同清晰度和编码在选择框中切换。读到当前作品的博主昵称时，保存文件名会以昵称开头，例如 `博主昵称-作品标题-作品ID-清晰度.mp4`；读不到昵称时沿用原文件名。

下载在抖音页面中发起，以保留视频服务器要求的来源信息，避免扩展直连返回 403。主地址失败时自动尝试页面提供的备用 CDN；只有完整取回 MP4 后才创建保存任务。弹窗关闭后取回过程继续，刷新或关闭抖音标签页会中断尚未完成的取回过程。权限维持不变，不读取 Cookie。

支持 `douyin.com/video/<作品 ID>` 和用户页 `?modal_id=<作品 ID>`。如果页面没有提供直接的 HTTPS 视频源，扩展会提示失败，不会尝试提取浏览器会话材料或绕过站点限制。请仅下载你有权用于本地参考的内容；不要把参考片画面或声音直接用于新作品发布。
