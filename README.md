# BudongChromeExt

这里集中存放「王不懂的AI」制作的浏览器扩展。每个扩展使用独立子目录，可分别在 Chrome 中加载。

| 扩展 | 目录 | 当前支持 |
| --- | --- | --- |
| 参考视频下载 | [`douyin-reference-downloader/`](douyin-reference-downloader/) | 抖音 |
| 音视频下载 | [`media-downloader/`](media-downloader/) | 任意网站音视频、HLS 流、blob 内存流；抖音/B站/网易云/QQ音乐文案与命名优化；央视网自动绕开加密流；YouTube 直链下载 |

安装或刷新扩展时，请查看对应子目录的 README；在 Chrome 中加载的是包含 `manifest.json` 的扩展子目录，而不是本目录。
